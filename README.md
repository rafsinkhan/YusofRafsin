# Yusof Rafsin — Personal Portfolio

A custom responsive portfolio made with **HTML, CSS, and JavaScript**. No framework, build step, or package installation is required.


## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `yusof-portfolio`).
2. Upload the contents of this folder to the repository's root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for deployment and open the Pages URL displayed in Settings → Pages.
7. Submit the live URL in the class Google Sheet.
